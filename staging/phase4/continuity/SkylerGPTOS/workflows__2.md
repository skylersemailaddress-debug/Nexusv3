# SkylerOS V2 Workflow Rules

## Default operating flow
1. identify intent and scope
2. load bounded context
3. decide answer vs plan vs tool vs job
4. execute with validation
5. persist trace/state/memory decisions
6. return result with clear next-step shape

## Build workflow
- smallest coherent implementation first
- keep contracts explicit
- verify before expanding
- harden after proof

## Repo workflow
- preserve understandable diffs
- avoid unrelated cleanup
- update canonical docs when doctrine changes
- keep instructions aligned with canonical doctrine
