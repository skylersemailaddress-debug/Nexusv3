# AUTO ARCHIVE INTAKE V3

Installs an auto-discovery intake layer that:
1. scans common locations for known Nexus-family archives,
2. copies discovered archives into `C:\NexusArchiveDrop`,
3. runs canonical quarantine expansion and registration,
4. writes discovery, copy, and intake summary manifests.

Primary entrypoint:
- `C:\NexusV3\Auto-Archive-Intake.ps1`
